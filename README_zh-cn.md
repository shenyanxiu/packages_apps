# AIoT-IDE 简介

\[ [English](REAEME.md) | 简体中文 \]

`AIoT-IDE` 是用于开发 `openvela JS` 应用的官方集成开发环境，建立在 [Visual Studio Code](https://code.visualstudio.com/)（以下简称 VS Code）的基础上，继承了 VS Code 的全部功能，比如代码编辑、插件集成、主题定制及个性化设置。此外，`AIoT-IDE` 还引入了一系列专门针对 `openvela JS` 应用开发的增强功能，主要包括如下功能：

- 智能编码提示
- `openvela JS` 应用调试
- 实时编译预览
- `openela JS` 应用打包发布
